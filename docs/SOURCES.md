# Sources

The first version of this checklist was distilled from 20 Instagram reels on
vibecoding risk (April to September 2026). Every dated rule and penalty figure
in the agent prompts was then checked against a primary source on 2026-09-29.
Those checks are logged here.

The creators' own figures that couldn't be tied to a source are kept only as
reported cases, never as penalties. Examples: the $10K AI-usage bill, the
13,000 leaked ID photos, and the share of vibecoded apps with an exposed
database. They show what goes wrong. They don't predict what an app will owe.

When a rule changes, update the prompt, update the row here, and change the
date.
