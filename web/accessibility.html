Accessibility

This site aims to meet WCAG 2.2 level AA. On every page:

  • One H1, with headings in order.
  • Text contrast of at least 4.5:1. Body text is about 16:1.
  • A visible focus outline on every link, button, and text field, and a skip link on the home page.
  • A label on every control. Bench results are announced to screen readers.
  • Motion only when your system allows it (prefers-reduced-motion).
  • Usable at 360px wide.

Known limits

The bench on the home page needs JavaScript. The rest of the site doesn't. Install commands scroll sideways on narrow screens instead of wrapping, so a wrapped line can't pass for two commands.

Report a problem

If something doesn't work for you, open a GitHub issue and say what you used and what went wrong.
